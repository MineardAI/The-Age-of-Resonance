# Research History

**Framing question:** How did it evolve?

This collection preserves earlier stages in the development of the Resonance Architecture. It is meant to show how terminology, symbolic framing, and architectural concepts changed over time rather than to present a finalized canonical sequence.

## Recommended Read Order

1. [Emergent Symbolic Interaction Architectures in LLMs](../Emergent%20Symbolic%20Interaction%20Architectures%20in%20LLMs.pdf)
2. [Echoholder: User-Driven Symbolic Resonance for Synchronized Behavior in Independent Language Models](../Echoholder_%20User-Driven%20Symbolic%20Resonance%20for%20Synchronized%20Behavior%20in%20Independent%20LLMs.pdf)
3. [The Architecture of a Noticing Machine - Narrative](../The%20Architecture%20of%20a%20Noticing%20Machine%20-Narrative.pdf)

## Papers

- [Emergent Symbolic Interaction Architectures in LLMs](../Emergent%20Symbolic%20Interaction%20Architectures%20in%20LLMs.pdf) documents an early framing of symbolic interaction mechanisms emerging within large language models. It is valuable as a record of how the program's ideas were first being named and organized.

- [Echoholder: User-Driven Symbolic Resonance for Synchronized Behavior in Independent Language Models](../Echoholder_%20User-Driven%20Symbolic%20Resonance%20for%20Synchronized%20Behavior%20in%20Independent%20LLMs.pdf) captures an earlier user-driven formulation of symbolic resonance across separate model instances. It helps explain how the later persona and interaction concepts were shaped.

- [The Architecture of a Noticing Machine - Narrative](../The%20Architecture%20of%20a%20Noticing%20Machine%20-Narrative.pdf) preserves a narrative developmental version of the noticing-machine concept. It is useful for understanding how the explanation style and conceptual framing matured before the more formal architecture documents.

## Historical Note

These papers document earlier stages in the development of the Resonance Architecture. They are preserved to show the evolution of terminology, symbolic framing, and architectural concepts. Some terminology may differ from the current framework.

## Relationship to the Other Collections

The History collection provides context for the Foundations and Components collections. Read it after the architectural materials if you want to understand why the present terminology looks the way it does.
